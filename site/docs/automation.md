# 모아 자동 갱신 계약

개인 사이트의 원본은 승인된 수집기의 SQLite이며 이 사이트는 변경분 조회용 D1을 사용한다. 전체 데이터 재생성이나 임의 일정·참석자 추정은 하지 않는다.

연결된 사이트 MCP는 `schedule_status`, `schedule_list`, `schedule_attention`, `schedule_apply_delta`를 제공한다. 조회는 로그인한 사람의 데이터만 대상으로 한다. 변경 반영에는 수집기가 발급한 installationId, 단조 증가 sequence, schemaVersion=2와 records를 그대로 사용한다. 같은 배치는 같은 내용·sequence로 재시도하고 성공 후 수집기의 outbox를 승인한다. 빈 로컬 DB를 새로 만들어 전체 수집 성공으로 처리하지 않는다.

MCP만으로 로컬 Mac의 카카오톡이나 파일에 접근하지 못한다. Mac 실행 권한이 없으면 저장된 데이터 조회·이미 수집된 변경분 반영까지만 보고한다. Gmail·네이버·Google Calendar·Discord 수집은 별도의 승인된 로컬 주기 작업을 사용한다. 카카오톡 신규 순회는 현재 중단 상태다.

Mac 주기 작업은 15분 간격으로 수집·분석·증분 전송·푸시를 수행한다. 사이트 서비스 인증은 origin별 시스템 키체인, 사용자별 쓰기 인증은 별도 연결 키를 사용한다. Git 배포 자격 증명을 저장하거나 무인 수집 인증으로 재사용하지 않는다.

푸시는 사용자가 기기에서 켠 경우만 발송한다. 구독과 처리 상태는 사용자별 격리, 임대 기반 중복 방지, 최대 3회 재시도, 404/410 구독 제거를 사용한다. 전달 후 ack 이전 종료 시 재전달할 수 있으므로 브라우저 tag와 Push Topic으로 합친다. Mac 수면·오프라인 중 발송 보장은 없으며 알림 수신은 브라우저/OS 권한에 달려 있다. 잠금 화면에는 개인 일정 제목을 넣지 않는다.
