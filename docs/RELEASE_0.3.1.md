# 0.3.1 개발 미리보기

모집방 공지와 공유 캘린더를 개인 참석 일정으로 오인하는 문제를 수정했습니다. 사용자별 방 제외 정책은 원본을 보존하면서 화면에서 숨기며 재수집해도 유지됩니다.

Calendar 첫 페이지 누락을 막는 페이지 순회, 기본 캘린더의 사람 연결, 공유 캘린더 분리를 추가했습니다. 명시적인 Gmail Calendar 알림은 날짜·제목으로 유일하게 맞는 기존 일정에 근거를 연결합니다. 전체 메일의 자유형 추출이나 Calendar syncToken 상시 동기화는 아직 완료되지 않았습니다.

검증: Python 83개, TypeScript와 Sites 빌드. 실제 모집방 일정 87개 제외, Calendar 89개 확인(내 캘린더/근무 19개, 공유 업무 70개), Gmail 알림 10개와 네이버 알림 1개 근거 연결. 마지막 재동기화는 요청 0회입니다. 개인 데이터와 키는 패키지 밖에 보관합니다.
