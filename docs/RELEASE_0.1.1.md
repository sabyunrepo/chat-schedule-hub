# 0.1.1 개발 미리보기

카카오톡에서 접근성 요소 기반 스크롤이 실패할 때 현재 화면으로 검증한 좌표로 복구하는 절차를 추가했다. 도구의 성공 응답과 실제 화면 변화, DB 저장 완료를 구분한다. 호스트 컴퓨터 유즈 자체의 오류를 수정한 릴리스는 아니다.

- `kakao-observe`: 실제 전체 AX 관찰 2개를 정규화해 기존 선별 저장 경로에 연결.
- 조용한 채팅방과 최근 30일 비활동 방을 본문 처리 전에 제외.
- 요소 번호·읽지 않은 인원 변화는 진행에서 제외. 카드의 모임 시각을 발언 시각으로 사용하지 않음.
- 오류·방 변경·무변화 때 저장 체크포인트 전진 금지.
- 배포 수집 스킬과 수집 경로 추가 스킬 갱신.

검증: 테스트 58개 통과. 실제 카카오톡에서 좌표 스크롤 3회 연속 화면 변화 확인. 추가 메시지 2개 선별 저장(Decisions 약 610ms), 같은 배치 재처리는 모델 호출·신규 저장 0. 카카오톡 로컬 보존 메시지는 총 12개이며 전체 30일 수집은 미완료다.

설치 패키지는 호스트에서 사용하는 스킬과 로컬 실행 코드다. 호스트에 컴퓨터 유즈 기능이 필요하다. 독립적인 카카오톡 백그라운드 수집기, 전체방 수집 완료, 마켓 심사 승인이나 모든 Codex 환경의 설치 호환성을 의미하지 않는다. 키·사용자 설정·수집 데이터는 포함하지 않는다.
