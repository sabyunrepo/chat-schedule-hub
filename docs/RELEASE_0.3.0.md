# 0.3.0 개발 미리보기

대시보드 동기화를 전체 교체에서 레코드별 변경 전송으로 바꿨습니다. 추가·수정된 일정/인물/수집 상태만 저장하며, 변경이 없으면 요청을 보내지 않습니다. 실패한 요청은 정확한 pending 본문으로 재시도합니다.

사이트 sync API v2와 수집기 버전을 함께 갱신해야 합니다. 기존 snapshot은 일회성 마이그레이션으로 보존하고 누락을 삭제로 처리하지 않습니다. 필터와 개인 데이터는 유지됩니다.

카카오톡 명시 일정 카드 추출, Calendar 날짜 지원, Dot 원격 운영 검토를 포함합니다. Dot 연결·예약 실행과 자유형 대화 전체 일정 추출은 미검증/미완료입니다.

검증: Python 80개, SQL 마이그레이션/재전송/사용자 격리 검사, TypeScript 검사와 Sites 빌드. 실제 사이트 일정 98개 반영 후 재전송 0회, 일정 10개 변경 시 10개만 전송 확인. 계정·키·수집 DB는 패키지에 포함하지 않습니다.

상세: [증분 동기화](INCREMENTAL_SYNC.md), [Dot 검토](DOT_REMOTE_COLLECTION.md). 문제 시 수집기 동기화를 중단하고 DB를 보존합니다. API v1로는 현재 서버에 동기화할 수 없습니다. 공개 미리보기이며 마켓 심사 승인을 뜻하지 않습니다.
