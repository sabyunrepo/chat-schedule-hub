# Discord 웹

- 방식: 호스트 컴퓨터 유즈가 렌더링된 UI를 관찰해 공통 배치를 전달한다. 독립 무인 드라이버는 미구현이다.
- 범위: 허용 서버의 접근 가능한 모든 채널과 활성/보관 스레드. 스레드는 URL ID 기준 별도 target, config.parentTargetId로 채널 연결.
- 탐색: 채널 목록과 스레드 목록을 각각 스크롤한다. 숨김/권한 없음/미열람을 구별하고 부모 완료로 자식 완료를 추정하지 않는다.
- 가상화: 실제 스크롤로 추가 본문 로딩 확인. 최근 이동 직후의 로딩 중 상태는 끝이 아니다.
- 식별: 채널·스레드 URL 확인. 메시지 원본 ID의 UI 복사 및 해당 딥링크 재접근을 한 건 확인. 복사 직후 오래된 클립보드가 반환될 수 있으므로 형식/대상 일치를 확인해야 한다. 대량·반복 식별은 미검증. 임시 겹침 키는 반복·수정 메시지의 일반 식별 보장이 아니다.
- 수정/삭제: 수정 표시가 보이는 경우 기록 가능. 화면 부재는 삭제 증거가 아니다.
- 첨부: 이미지/파일은 미해석으로 표시. 자동 다운로드나 숨은 API 사용 없음.
- 검증: docs/PILOT_REPORT.md. 전체 기간·보관 목록 완전성·무인 처리량 미검증.
