# 카카오톡 Mac

## 2026-11-01 직접 수집 검증 갱신

루트 에이전트가 일반방과 오픈채팅을 직접 확인했다. 아래의 초기 파일럿 수치와 대기 상태는 과거 기록이다. 최근 실행에서는 모집방의 25건 및 49건 배치 저장 후 각각 재실행하여 신규 저장 0, API 호출 0을 확인했다. 전체 30일 탐색 완료를 뜻하지 않는다. 일반방의 이전 구간, 날짜 미확인 메시지, 모집방 과거 구간은 여전히 미완료다.

일정 카드 본문이 Help/Value 시각과 같은 줄에 노출되는 형식, 한 단계 얕은 스크롤 막대, 마지막 빈 row를 파서에서 처리한다. 숫자로 시작하는 본문 줄은 보존한다. 말풍선의 발언 시각과 카드의 행사 날짜를 섞지 않는다. 긴 본문의 `전체보기`는 실제 창에서 재확인하며 생략된 내용을 생성하지 않는다.

선별 규칙 v7은 relevance=0인 uncertain 메시지를 그 라벨만으로 보존하지 않는다. 날짜·정정 단서, 관련 메시지의 이웃 맥락, review 판단은 기존처럼 보존한다. v6에서 보존 범위를 줄이는 변경이므로 기존 v6 커서를 호환하되, 오래된 다른 규칙은 재관찰을 요구한다. 이미 저장된 본문은 자동 삭제하지 않는다.

겹침 창의 즉시 반복 검증과 멀리 떨어진 창의 재방문은 다른 문제다. 현재 발생 키 레지스트리는 마지막 창만 유지하므로 재방문 전체 중복 방지는 미완성이다. 원문 시각/본문이 다른 파서 버전으로 표현된 기존 기록도 자동 병합하지 않는다. 신규 구간을 연결할 때 기존 저장 근거를 대조하고, 불명확하면 저장 완료로 처리하지 않는다.

UI 창 연결 실패와 도구 시간 초과를 실제로 관찰했다. 연결 후 대상 방 제목과 마지막 위치를 다시 확인하고, 메모리에만 있는 미저장 구간은 재관찰해야 한다. 텍스트 편집기 경유 파일 전달은 시간 초과로 검증하지 못했으며 지원되는 자동 수집 경로로 간주하지 않는다.

## 현재 제외 정책

사용자 요청으로 카카오톡 ‘조용한 채팅방’ 보관함과 최근 30일 대화가 없는 방을 모두 제외한다. 알림 음소거는 조용한 채팅방 보관과 같은 것으로 취급하지 않는다. 마지막 활동 날짜가 불명확하면 제외 확정 대신 확인 대기로 남긴다. 목록에서 활동이 다시 확인된 방은 재평가하되 조용한 채팅방은 계속 제외한다. 제외 폴더 내부는 열지 않는다.

`hub/sources/kakao_collection.py`가 제외 판정을 모델 호출보다 먼저 적용하고, 확인된 두 UI 관찰의 겹침 메시지를 기존 select-ingest로 전달한다. 방 기록은 비공개 SQLite에만 저장한다. 원본 메시지 ID가 없으므로 발생 키는 관찰된 겹침 범위에서만 검증된다. 전체 탐색 완료나 수정 식별을 보장하지 않는다.

실제 모집방 파일럿: 8개 보존, Decisions 1회 약 397ms. 동일 배치 반복은 모델 호출 0, 신규/수정 0. 과거 구간 탐색 중 UI 창 좌표 오류 및 도구 시간 초과가 발생하여 30일 수집 완료로 처리하지 않았다. 다른 활동 방도 아직 대기 상태다.

Current runtime status (supersedes earlier pending Gateway status): [2026-11-01 continuous collection](../CONTINUOUS_COLLECTION.md).

- 방식: 호스트 컴퓨터 유즈로 앱 UI를 읽고 공통 배치를 전달한다. 일반방과 오픈채팅 목록은 각각 탐색한다.
- 범위: 모든 방 요청이라도 단일방 파일럿 수용 후 확대한다. 방 목록 화면 하나가 전체 목록은 아니다.
