# 2026-11-01 실제 UI 수집 시간 측정

활동 중인 오픈채팅 한 방을 직접 컴퓨터 유즈로 탐색했다. 조용한 보관함을 열지 않았으며 최근 30일 범위만 저장 대상으로 삼았다. 방 이름과 원본 대화는 배포 문서에 포함하지 않는다.

| 구간 | 실측 |
| --- | --- |
| 작은 창에서 연속 스크롤·AX 관찰 5회 | 9.03초 |
| 세로 확대 후 연속 스크롤·AX 관찰 10회 | 18.86초 |
| 동일 위치에서 확대 전후 표시 행 | 10 → 13 |
| 첫 화면 독립 관찰 2회 | 3.29초 + 1.27초 |
| 실제 메시지 4건 판단·저장 | 1.755초 (API 1.740초) |
| 다른 실제 메시지 4건 판단·저장 | 0.346초 (API 0.340초) |

측정 시작 후 중간 집계까지 벽시계 경과는 409.317초(6분 49초)였다. 사용자 피드백, 입력 검토, 원인 조사 및 코드 수정을 포함한다. 순수 도구 실행 시간과 방 전체 완료 시간을 혼동하지 않는다. 창 크기 비교의 다른 페이지들은 내용 밀도가 달라 일반적인 배율 성능 향상으로 해석하지 않는다.

## 저장 검증

- 기존 운영 DB 422건에서 430건으로 증가, 해당 방은 40건에서 48건으로 증가.
- 이번 두 묶음은 독립적으로 읽은 화면 간 유일한 연속 3행 이상을 확인했다. 같은 화면을 복사해서 독립 관찰로 사용하지 않았다.
- 동일 방의 본문·발언 시각 중복 그룹 0. 실제 Decisions 호출 2회, 신규 저장 8건.
- 날짜 경계보다 오래된 화면까지 탐색했지만, 날짜/작성자 생략 및 미해석 이미지가 있어 **전체 기간 수집 완료 아님**.
- 선별 저장을 확인한 것이며 일정 추출·사이트 반영 완료 수치가 아니다. 기존 0.4.5 자동 scan 루프 전체가 실제 방에서 통과했다는 의미도 아니다. 이번 확정 묶음은 collect 경로로 저장했다.

## 반영한 보완

- 오픈채팅의 별도 작성자 텍스트를 본문과 분리한다.
- 이미지·이모티콘만 있는 행을 삭제하지 않고 None 공백으로 유지한다. 이를 사이에 둔 텍스트를 연속 3행으로 오인하지 않는다.
- 시간·작성자 미확인을 이웃 값으로 채우지 않는다.
- 수집 스킬에 창 세로 확대, 짧은 연속 관찰 버퍼, 날짜 경계 즉시 중단과 측정 항목을 명시한다.

남은 병목은 화면 해석/호스트 왕복 및 안전한 식별이 안 되는 메시지다. 넓은 창과 짧은 버퍼를 기본으로 사용하되, 미해석 메시지를 건너뛴 순회를 완료 경계로 승격해서는 안 된다. 최신 화면에 안전한 연속 3행이 없으면 현재 scan 프로토콜은 재검토가 필요하다.
