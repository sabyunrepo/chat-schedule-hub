# 0.3.2 개발 미리보기

지난 일정이 다가오는 일정에 남던 문제를 수정하고, 앞으로의 일정 전체를 표시합니다. 진행 중과 일정 미정은 구분합니다. 내부 근거 ID는 유지하되 화면에는 출처·원문 발췌·확인 시각·안전한 원문 링크를 표시합니다.

간트는 제목을 짧은 기간 막대와 분리하고 줄바꿈합니다. 겹치지 않는 일정은 같은 줄로 배치하고 인물·날짜 헤더는 고정합니다. 수집 상태는 수집 연결에서만 표시합니다.

검증: Python 83개, 날짜 경계 9개, 간트 배치 검사, TypeScript, Sites 빌드. 후보 날짜 조율을 확정 날짜로 만들지 않으며 일반 자유형 대화 추출은 여전히 제한적입니다.
