# 0.2.0 개발 미리보기

기존 카카오톡·Discord 수집 구현과 Gmail·네이버 메일·Google Calendar 읽기 연결을 재사용 가능한 플러그인으로 정리했습니다.

- 수집 실행, 메일·캘린더 연결, 새 수집 경로 추가 스킬 3개.
- Desktop OAuth/PKCE, 토큰 갱신, 네이버 IMAP 읽기 전용 파일럿.
- 메일 선별·중복 방지와 구조화 캘린더 일정 변경/취소 반영.
- 카카오톡 날짜 앵커·카드 파싱 개선, Discord 공식 봇 운영 절차.
- 인증/복구 실행 안내, 소스 계약, 확장 계획, 패키지 참조 검사.

검증: Python 테스트 75개, 스킬 3개 형식 검사. 실제 Gmail·네이버·Calendar 연결과 각각 최대 10개 파일럿, 재처리 중복 방지를 확인했습니다. 자격 증명·실제 수집 데이터·개인 사이트 설정은 포함하지 않습니다.

ZIP을 별도 디렉터리에 풀어 README의 명령을 실행합니다. 호스트의 로컬 실행 및 컴퓨터 유즈 기능과 사용자별 인증이 필요합니다. Google 연결은 Python 3.11+ 가상환경에서 requirements-mail.txt를 설치합니다.

메일·Calendar 상시 증분 수집, 메일 자유형 일정 추출, 새 데이터의 Sites 동기화는 미완료입니다. 설치 패키지/공개 미리보기이며 Codex 설치 수용 검증·마켓 심사 승인·정식 배포가 아닙니다. 라이선스 조건은 LICENSE.md를 따릅니다.

문제 발생 시 새 메일/Calendar 명령 실행을 중단하고 기존 0.1.1 패키지를 별도 디렉터리에서 사용합니다. 개인 DB·토큰은 삭제하거나 되돌리지 않습니다. 이 릴리스는 상시 서비스를 새로 설치하지 않습니다.
