# 일정 채팅 구현

2026-11-01. 실제 ChatGPT 화면 분석은 [REA 기록](REA_CHATGPT_REFERENCE.md)을 참조한다.

- 일정 채팅 탭: 새 대화, 최근 대화 기록, 우측 질문, 본문 답변, 하단 입력창, 복사, 일정 상세 링크, 응답 받기 중지. 예시/홍보 카드 없음.
- Codyssey `gpt-5.4-mini`의 함수 호출을 서버에서 실행한다. `ChatProvider` 인터페이스와 공급자 구현을 분리했다. 직접 원격 MCP를 공급자에 넘기는 방식은 아니다.
- 도구: `schedule_search`, `schedule_undated`, `schedule_get`, `schedule_attention`, `propose_review`. 확인/추적 제안은 적용 버튼을 눌러 기존 `/api/attention`의 revision/version 검사를 통과해야 저장된다. 수집기용 delta 쓰기나 임의 SQL/URL/셸을 모델에 제공하지 않는다.
- 외부 캘린더 변경·메일 발송·새 일정 생성/시간 수정은 포함하지 않는다.
- Sites의 `CODYSSEY_API_KEY` secret을 사용한다. 브라우저에는 전달하지 않는다. 질문/최근 대화/조회된 일정 및 필요한 근거 일부가 Codyssey로 전달되며 설정 화면에도 표시한다.
- D1 `chat_threads`, `chat_turns`에 owner별 증분 저장한다. 요청 ID 재전송 시 완료 답변을 재사용한다. 대화별 100초 잠금, API 85초 제한, 하루 100질문, 최근 8개 완료 턴만 문맥에 포함한다.
- 일정 검색은 최신 revision을 먼저 선택하고 조건 검색한다. 20건 페이지, 최대 offset 2000, 상세 근거 3건×600자. 일시와 종일/종료일 제외·현재 시간 상태를 모델에 제공한다.
- DB 인덱스: owner+thread+created, owner+created, owner+updated, sync owner+kind+id+updated.
- 모델 호출 최대 5라운드/도구 8회. 잘못된 도구 인수는 실행하지 않는다. 공급자 에러 본문이나 비밀을 사용자/로그에 반환하지 않는다.

## 검증

- 타입 검사 통과. 기존 5개 회귀 파일 및 채팅 도구 루프·잘못된 인수·취소·한도·소유자 인수 거부·키/오류 처리 테스트 통과.
- 최신 제외 revision/사용자 격리/동시 대화 잠금/날짜 미정 SQL 조건을 합성 SQLite에서 검증했다.
- 모든 SQL 마이그레이션을 빈 SQLite에 순서대로 적용했다.
- 데스크톱/390px 모바일 입력창·스크롤·탐색 UI 확인. 모바일 실제 키보드는 별도 검증 대상.
- REA MCP initialize와 tools/list 성공: v6.8.0, 도구 229개, capture_browser_scenario 포함. 현재 세션의 웹 분석은 CLI로 실행했다.

## 범위/후속 개선

- 현재 응답은 완료 후 표시된다. 글자 단위 스트리밍은 미구현이다. 중지는 브라우저 요청/서버 abort를 전달하지만 공급자의 이미 소비된 비용 취소를 보장하지 않는다.
- 확인/추적 변경은 실제 사용자가 누를 때만 적용한다. 실제 개인 확인 항목을 검증 목적으로 변경하지 않는다.
- 대화 목록 50개, 대화별 최근 30턴 표시. 오래된 기록 페이지네이션·대화 삭제·요약 압축은 후속 범위다.
- 실제 캘린더 수정은 별도 사용자 override 계층과 원본 변경 충돌 정책이 필요하다.

## 실제 배포 검증

- 비공개 Sites 배포 성공. 소스 `e51db9ff9c430a92e8ed042595fca85feb2cd099`.
- 최초 실질문에서 모델이 날짜 미정 일정을 찾지 못하는 문제가 나타나 `schedule_undated`를 분리하고 검색 지침을 수정했다.
- 보완 후 실제 대화에서 `schedule_undated(kind=crime, onlyMe=true)`가 1건을 반환했고, 저장된 일정 제목/확인할 점/상세 링크가 표시되었다. API 기록과 대화 기록 다시 열기로 재확인했다.
- 모델의 모든 질문에 대한 정확도를 보장하는 결과는 아니다. 애매한 날짜/사람/동일 모임 판단은 근거와 함께 검토해야 한다.
