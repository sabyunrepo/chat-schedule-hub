# 수집 경로 추가

이 스킬은 Chat Schedule Hub 프로젝트와 배포 플러그인의 수집 경로 확장 작업용이다. 스킬을 만든 것만으로 런타임 수집기가 추가되지는 않는다.

## 기준 자료

프로젝트 루트의 AGENTS.md와 PLAN.md를 읽는다. 상세 규격과 수용 기준은 [수집 계약](../../docs/SOURCE_ADAPTER_CONTRACT.md)을 따른다. 경로는 이 SKILL.md가 있는 디렉터리 기준이다. 플러그인으로 패키징할 때 해당 참조를 함께 포함하고 링크를 검증한다.

## 진행

1. 사용자 요청에서 대상 서비스·앱/웹/API/파일 방식·계정/대상 범위를 확인한다. 불명확한 범위의 실제 데이터를 수집하지 않는다. 조사·설계·합성 샘플 작업은 먼저 진행할 수 있다.
2. 공식 문서와 허용된 실제 화면에서 ID, 시간, 가상 스크롤, 재개·수정·삭제 감지 특성을 확인한다. 현재 세션 도구의 존재를 플러그인 재배포 가능성의 증거로 삼지 않는다.
3. docs/sources/<adapter-id>.md에 계약 7절의 수집 특성을 기록한다. 미확인과 unsupported를 구분한다.
4. SourceAdapter와 설정 스키마·등록 정보를 추가한다. 공통 저장/분석/일정/동기화 기능을 복제하지 않는다. 공통 의미가 맞지 않으면 억지로 매핑하지 말고 계약 변경과 기존 경로 영향부터 설명한다.
5. 체크포인트는 후보만 반환하고 저장 커밋은 공통 계층에 맡긴다. 미완료 중간 구간과 이미 확인한 경계를 구별한다. 앱 읽음 표시는 커서로 사용하지 않는다.
   카카오톡은 사용자 설정의 조용한 채팅방 및 비활동 방 제외를 본문 접근·모델 호출 전에 적용한다. 마지막 활동 미확인, 음소거, 보관 상태를 혼동하지 않는다. UI 시간 초과나 창 좌표 실패를 기간 완료로 처리하지 않는다.
6. capability에 맞는 계약 검증을 수행한다. 합성 자료로 실패 복구·중복·격리를 먼저 확인하고, 승인된 소규모 실제 범위에서 검증한다. 실제 사용자가 지정한 수집 방식을 임의로 바꾸지 않는다.
7. 온보딩·등록·배포 포함 목록·문서를 연결한다. 지원되는 기능, 수집 한계, 검증 환경과 결과를 보고한다.

## 완료 기준

계약의 필수 수용 기준을 충족하고 공통 파이프라인에 연결되어야 한다. 문서만 갱신한 요청에서는 런타임 구현·등록·실데이터 검증이 미완료임을 명시한다. 배포용 샘플에는 실제 메시지·계정·토큰을 넣지 않는다.
